# Registro de Asistencia en Solana

## Descripción
Este proyecto es un programa desarrollado en la blockchain de Solana utilizando Rust y el framework Anchor.

Permite registrar usuarios en la blockchain almacenando su nombre y su dirección de wallet.

## Funcionalidad
El programa permite:
- Registrar un usuario
- Guardar su nombre
- Asociar su wallet en la blockchain

## Tecnologías utilizadas
- Solana
- Rust
- Anchor

## Ejecución
El programa fue compilado correctamente utilizando Anchor.

El despliegue en red puede realizarse en Devnet o Testnet.  
No se realizó el despliegue debido a limitaciones de la red, pero el programa está listo para ejecutarse.
